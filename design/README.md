# Handoff: iFix — сайт сервісу ремонту Apple-техніки

## Overview
Шість екранів для сервісу ремонту iPhone/iPad/Apple Watch у Львові та Новому Розділі: головна,
послуги, каталог моделей, сторінка моделі, ремонт поштою, кабінет клієнта. Мета сайту — заявка на
безкоштовну діагностику; цін на сайті немає, комунікація будується навколо «фіксована ціна до початку робіт».

## About the Design Files
Файли `*.dc.html` у цьому пакеті — **дизайн-референси в HTML**, а не продакшн-код. Вони відкриваються
в браузері й показують задуманий вигляд, стани та анімації. Завдання розробника — **відтворити ці
екрани в цільовій кодовій базі** (Next.js/React, Vue, Astro тощо) її звичними патернами й
бібліотеками. Якщо кодової бази ще немає — обрати доречний стек (рекомендація: Next.js App Router +
CSS Modules або Tailwind) і реалізувати макети там. `support.js` — рантайм середовища, у якому
малювались макети; у продакшн він НЕ переноситься.

Розмітку всередині файлів можна читати як точний референс: усі стилі інлайнові, значення видно
напряму. Логіка (стан, фільтри, форми) лежить у `<script data-dc-script>` наприкінці кожного файлу.

## Fidelity
**High-fidelity.** Кольори, типографіка, відступи, радіуси, стани й анімації фінальні — відтворювати
піксель-у-піксель. Виняток: фотографії — це тимчасові плейсхолдери (див. Assets).

## Interactions & Behavior
- **Навігація:** усі переходи — звичайні посилання. Каталог → модель через query-параметр `?m=`.
- **Форми:** локальний стан, `preventDefault`, валідація на клієнті (ім'я > 1 символу, телефон ≥ 9 цифр),
  екран успіху з кнопкою «Надіслати ще одну». Помилка — рядок `#EDFFA6` під полями.
- **Фільтри й пошук** — миттєві, без запиту на сервер (дані в масиві).
- **Акордеони** — `grid-template-rows: 0fr/1fr` + `overflow: hidden` (без `max-height`-хаків).
- **Анімації входу:** `nUp .6–.85s cubic-bezier(.2,.7,.2,1)` зі сходинками затримок 0 / .06 / .12 / .18s.
- **Hover:** картки `translateY(-3…-5px)` + лаймова межа; рядки списків `translateX(4px)`;
  фото `scale(1.07)` і зняття `grayscale`; тривалості .2–.5s.
- **Постійні:** `nDrift` (світлова пляма 22–24s), `nFloat` (фото 8s), `nHalo`+`nShine` (головна CTA 4.5s),
  `nDot` (пульс індикатора 2.6s), `nTicker` (стрічки 32–34s).
- **Reduced motion:** `@media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }` — обов'язково.
- **Адаптив:** усі сітки `auto-fit/auto-fill + minmax`, жодних фіксованих ширин; перевірити на 360px.

**Типографіка:** Unbounded 300/400/600 (заголовки), Manrope 400/500/600 (текст), Google Fonts.
H1 `clamp(34px,5.2vw,68px)/1.02/-.035em/600`; H2 `clamp(27px,3.4vw,46px)/1.06/-.03em/400`;
H3 19–23px Unbounded 400 `-.02em`; body 15–18.5px/1.6; кікер 12.5px, `letter-spacing:.14em`, uppercase, акцент.

**Відступи:** контейнер 1280px, паддінг 28px; сітки `gap: 12–18px`, великі — `clamp(24px,4vw,72px)`;
секції `clamp(40px,6vw,100px)`; паддінг картки 20–26px, великих блоків `clamp(24px,3.4vw,42px)`.

**Радіуси:** пілюлі/кнопки/чипи `999px`; картки `24–26px`; великі блоки `30–32px`; поля `18px`;
іконка-квадрат `16px`; лого `13px`; чекбокс `8px`.

**Тінь:** тільки на акцентних кнопках при hover — `0 16px 40px rgba(218,255,61,.26)`;
пульсуюча — `nHalo` (`0 10px 30px rgba(218,255,61,.18)` ↔ `0 16px 46px rgba(218,255,61,.34)`).

**Фокус:** `:focus-visible { outline: 2px solid #DAFF3D; outline-offset: 3px; }`. `::selection { background:#DAFF3D; color:#0B0C0E; }`

**Keyframes** — точні визначення `nUp, nFloat, nDrift, nShine, nHalo, nDot, nGrow, nTicker, nRoll`
див. у `<helmet><style>` будь-якого файлу пакета (вони ідентичні) або в `iFix-Handoff.md`, розділ 2.
