# iFix — специфікація для розробки сайту

Дизайн-макети (відкриваються в браузері як є): `iFix Landing.dc.html`, `iFix-Services.dc.html`,
`iFix-Catalog-iPhone.dc.html`, `iFix-Model.dc.html`, `iFix-Mail-in.dc.html`, `iFix-Account v2.dc.html`.
Розмітка й стилі всередині — робочий референс: можна копіювати значення 1:1.

## 2. Анімації (спільний набір, копіювати як є)

```css
@keyframes nUp     { from { opacity:0; transform: translateY(24px); } to { opacity:1; transform:none; } }
@keyframes nFloat  { 0%,100% { transform: translateY(0); } 50% { transform: translateY(-12px); } }
@keyframes nDrift  { 0%,100% { transform: translate(0,0) scale(1); } 33% { transform: translate(-60px,40px) scale(1.12); } 66% { transform: translate(40px,-30px) scale(.95); } }
@keyframes nShine  { 0% { transform: translateX(-140%); } 55%,100% { transform: translateX(320%); } }
@keyframes nHalo   { 0%,100% { box-shadow: 0 10px 30px rgba(218,255,61,.18); } 50% { box-shadow: 0 16px 46px rgba(218,255,61,.34); } }
@keyframes nDot    { 0% { opacity:.6; transform: scale(.8); } 70%,100% { opacity:0; transform: scale(2); } }
@keyframes nGrow   { from { transform: scaleX(0); } to { transform: scaleX(1); } }
@keyframes nTicker { from { transform: translateX(0); } to { transform: translateX(-50%); } }
@media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }
```

Де застосовується:
- `nUp` — поява блоків при завантаженні (затримки 0 / .06s / .12s / .18s), easing `cubic-bezier(.2,.7,.2,1)`
- `nDrift` — світлова пляма в героях (радіальний градієнт лайму, 22–24s)
- `nFloat` — фото в героях (8s)
- `nHalo` + `nShine` — головна CTA-кнопка
- `nDot` — пульс індикатора «відкрито / у роботі»
- `nGrow` — прогрес-шкали (кабінет, процес, доставка)
- `nTicker` — бігуча стрічка (дубльований контент, `width: max-content`)
- Hover: картки `translateY(-4…-5px)` + межа акценту; фото `scale(1.07)` + `grayscale(.55) → 0`; рядки списків `translateX(4px)`; тривалості .2–.5s

## 3. Структура сайту

| Сторінка | Файл-макет | URL (пропозиція) |
| --- | --- | --- |
| Головна | `iFix Landing.dc.html` | `/` |
| Послуги | `iFix-Services.dc.html` | `/poslugy` |
| Каталог моделей | `iFix-Catalog-iPhone.dc.html` | `/modeli` |
| Сторінка моделі | `iFix-Model.dc.html` | `/modeli/{slug}` |
| Ремонт поштою | `iFix-Mail-in.dc.html` | `/poshtoyu` |
| Кабінет клієнта | `iFix-Account v2.dc.html` | `/kabinet` |

Шапка (sticky, `blur(16px)`, фон `rgba(11,12,14,.72)`) однакова всюди: логотип → Послуги, Моделі, Поштою, Кабінет, телефон, CTA «Записатись». Активний пункт — колір акценту.
Підвал: копірайт зліва, гарантія справа, розділювальна лінія зверху.

### Головна
Герой (бейдж статусу + H1 + опис + 2 CTA + картка з 3 показниками + фото) → Послуги (6 карток) → Смуга «репутація» на фото → Як це працює (3 кроки) → Моделі (групи чипів) → До і після (4 фото) → Відгуки (3) → Блок «поштою» → FAQ (`<details>`) → Перевірка статусу за номером → Форма запису → Підвал.

### Послуги
Герой → бігуча стрічка → фільтр (Усі / Швидкі при вас / Плата й вода / Корпус) + 12 карток послуг (іконка, номер, назва, опис, теги, термін, «Записатись») → Процес (4 кроки з анімованими шкалами) → 4 показники (0 ₴ / 30 днів / 40 хв / 15 хв) → Форма з вибором послуги.

### Каталог
Герой (лічильник моделей) → бігуча стрічка → фільтри (Усі / Нові / Популярні / Старші / iPad·Watch) + пошук по назві → сітка з 42 карток: фото 4:3, бейдж наявності, назва, рік, теги робіт, термін → CTA-блок «не бачите моделі».
Клік по картці → сторінка моделі: `iFix-Model.dc.html?m={encodeURIComponent(name)}`. У продакшені — ЧПУ `/modeli/{slug}`.

### Сторінка моделі
Хлібні крихти → герой (назва з URL, бейдж наявності, фото) → перемикач Оригінал/Аналог (змінює опис і текст першої роботи) → перелік 6 робіт із термінами → 3 гарантійні блоки → форма запису + список пов'язаних моделей.

### Поштою
Герой (2 CTA + картка показників 1–3 дні / 0 ₴ / 30 днів + анімований трекер) → 5 кроків → пам'ятка пакування (6 інтерактивних чекбоксів) → «що надсилають найчастіше» (6 фото-карток моделей) → трекінг за ТТН → форма відправки → FAQ-акордеон (4).

### Кабінет
Шапка з аватаром → активне замовлення (прогрес 62%, 4 стадії, хроніка, що розгортається) → 3 плитки статистики → історія з вкладками (Усі / У роботі / Завершені) → мої пристрої з гарантією → блок «новий ремонт».

## 4. Дані та інтеграції (що треба з бекенду)

- **Моделі:** `{ name, year, group: new|popular|old|other, jobs[], time, inStock, image, slug }` — 42 записи в `iFix-Catalog-iPhone.dc.html`.
- **Послуги:** `{ no, cat: quick|board|body, title, body, tags[], time, icon }` — 12 записів у `iFix-Services.dc.html`.
- **Заявка:** `{ name, phone, model|service, problem, source: landing|model|services|mail-in }` → CRM + Telegram-повідомлення майстру.
- **Ремонт поштою:** додатково `{ city, branch }`; відповідь — номер замовлення + адреса відділення в SMS.
- **Статус замовлення:** `GET /orders/{no}` → `{ device, work, stage, stages[], eta, log[] }` (зараз макет із заглушкою).
- **Кабінет:** авторизація за номером телефону + SMS-код; далі активні замовлення, історія, пристрої з датою завершення гарантії.

## 7. Технічні вимоги

- Мобільний фаст: усі сітки вже адаптивні, перевірити на 360px ширини.
- Мінімальна висота інтерактивних елементів — 44px (кнопки й поля вже 48–54px).
- Контраст: основний текст на тлі не нижче 4.5:1; лайм використовувати для великого тексту, іконок і плашок.
- Підтримка `prefers-reduced-motion` — обов'язкова.
- SEO: `title`/`description` на кожну сторінку, окремі URL моделей, мікророзмітка `LocalBusiness` і `Service`.
